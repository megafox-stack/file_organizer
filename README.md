
# File Organizer

A Python-based utility that automatically organizes files into structured folders based on their file types.

## Features

- Scans files within a selected directory.
- Identifies file types using extensions.
- Creates categorized folders.
- Moves files into their respective folders.
- Reduces manual file-management work.

## Technologies Used

- Python
- OS Module
- Shutil Module
- File System Operations

## Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/megafox-stack/file_organizer.git
   cd file_organizer
   ```

2. Run the Python application:

   ```bash
   python main.py
   ```

   Replace `main.py` with the actual entry-point filename if different.

## Project Objective

To simplify file management through Python automation and improve directory organization.
